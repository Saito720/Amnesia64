# IERS Earth-orientation data

`finals2000A.data` is an offline snapshot of the IERS Bulletin A rapid
Earth-orientation product distributed by the U.S. Naval Observatory. It
contains daily polar motion, UT1-UTC, length-of-day, and celestial-pole-offset
values, including predictions for approximately one year.

Source: https://maia.usno.navy.mil/ser7/finals2000A.data

Format: https://maia.usno.navy.mil/ser7/readme.finals2000A

Snapshot retrieved: 2026-08-16

Snapshot SHA-256: `39a7a48d8359103e84b720faa2298733e3f331ca03a278c358d56c291a297d8b`

Replace the data file periodically for accurate wall-clock operation. The file
format and path must remain unchanged; no engine rebuild is required.
