# SGP4

This directory vendors the C++ SGP4 reference implementation distributed with:

David A. Vallado, Paul Crawford, Richard Hujsak, and T. S. Kelso,
“Revisiting Spacetrack Report #3,” AIAA 2006-6753.

Source: https://celestrak.org/publications/AIAA/2006-6753/

Vendored files `SGP4.cpp` and `SGP4.h` are unmodified from the C++ reference
implementation in the conference source archive retrieved on 2026-08-16.
CelesTrak states that no license is associated with this code and that it may
be used for any purpose; attribution and a link to the publication are
requested.
